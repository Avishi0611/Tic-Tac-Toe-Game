# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

This project demonstrates basic DOM manipulation, event handling, and game logic implementation in JavaScript.

---

## 🚀 Features

- Two-player game (Player O and Player X)
- Automatic turn switching
- Winner detection
- Draw detection
- Reset Game button
- New Game button
- Simple and responsive UI

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 🎯 How to Play

1. Player O starts the game.
2. Players take turns clicking on empty boxes.
3. The first player to match three symbols in a row, column, or diagonal wins.
4. If all 9 boxes are filled and no player wins, the game ends in a draw.
5. Click **Reset** or **New Game** to play again.
